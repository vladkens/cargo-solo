# Pins by one command

Done: 2026-11-16, PR #2

`make pins` re-pins the packages in `src/packages.rs` and checks every file on every mirror. Run by hand when needed; no scheduled job.

## Why

A Debian point release replaces a package (`+deb13u1` by `+deb13u2`) and drops the old one from deb.debian.org, so a pin then comes only from snapshot.debian.org; rust-mingw moves with each Rust release. Re-pinning by hand means reading Debian's indexes and rustup's manifest and copying hashes. The person wants one command, and a way to check the links.

## Decisions

- `scripts/pins.py`, Python's standard library only, run with `uv run`. It rewrites the tables in place and prints what changed; the diff is the review.
- A Debian package's release is its mirror table's name (`TRIXIE` is trixie); its name and arch are in its path's file name. Its new path and SHA-256 come from `dists/<release>/main/binary-<arch>/Packages.xz` on the table's first mirror. A new package is a line with the empty hash.
- A release's snapshot moves to snapshot.debian.org's latest only when one of its packages changes, so that it still has every one.
- rust-mingw from rustup's stable manifest, `channel-rust-stable.toml`: its path, hash and the folder in its archive.
- The check is `every_package_is_on_every_mirror`, the test CI runs: `make pins` runs it after the script.

## Tasks

- [x] 3. Checked: a stale pin re-pinned, an empty hash filled, nothing changed when all are current.

## Result

`make pins` takes about 30 seconds: four Debian indexes (~40 MB) and rustup's manifest, then every file from every mirror. Its first run re-pinned rust-mingw from 1.99.1 to 1.100.0; every Debian pin was current, so no snapshot moved. A stale pin and an empty hash came back re-pinned, their releases' snapshots moved to the latest; a second run changes nothing. A snapshot older than a new package stops the script before it writes, so the next run tries again. Of buster's `all` packages a few are listed in two versions: such a package stops the script, to be pinned by hand.
